# ml_classifier_experiments

This is a friendly class-only Kaggle competition focused on classification.

Getting started

Step 1.  Find a partner.  Because we want you to push the edge, you will need to find a partner to work with for this assignment.  Use the  signup link to see who is available.  If you do not find a partner by Monday Oct 6 or so, we will randomly assign someone to you hopefully in a nearby time zone, although that's not critical.  This wouldn't stop you from getting started though.

Step 2.  Create a Kaggle account at kaggle.com.   If you use the link below, it will ask you to register so either way is fine. 

Step 3.  Use the participation URL (must use this to join as a team)  https://www.kaggle.com/t/dec4bb142a954450883fc5a30f718f99.

Step 4.  The competition will be held here for our class only: CSCI E-82 2026 | KaggleLinks to an external site.. You are to work in teams of 2 and there is a limit on the number of submissions per day per team.
Step 5.  Put your classification superpowers tCSCI E-82 2026 | KaggleLinks to an external site.o the test.  There is no pre-filled notebook.  You have a problem of maximizing classification accuracy for a dataset.  We are not going to tell you what the dataset is at this point so that you don't waste your time chasing possibilities with pre-training.  In most of the past years, the variable names have not been found to be useful so x, y, z variables do not correspond to a simple geometric interpretation.  You are welcome to use any methods.  
Each time you submit a set of predictions, you will receive a score for the set.  You will still want to perform training and test on your validation set, but you will send the best results to Kaggle to get feedback.  The winning team will have the best private score which corresponds to a second hidden dataset for which you cannot see the results. 

Is it OK to use AutoML methods?  Yes, but given the 2nd criteria below, we'd like you to start with a thought-driven manual approach.  You are welcome to follow it with an AutoML approach.

We will grade on three criteria: 

How well it works = 50%
How you got there in terms of smart ideas and effort 40% divided into the buckets of logic/insights + trying a number of ideas
How you leveraged feature importance and/or explainable AI.  These include variable importance, SHAP, LIME that we will discuss next week. 10%
Declaration of winners

There are public and private scores to prevent overfitting.  On the due date, we will declare a first set of winners.  Since some may elect to use grace period days, we will select a second set of winners when the competition ends 3 days later.

We will request that the winners to share their strategies during class on Tuesday. 

Minimal notebook documentation required

We are going to ask that you use a lab notebook principle while solving the problem.  That is, form and write a hypotheses, test the hypotheses, and describe your interpretation.  This lets your partner and grader follow the work and logic without having to read a line of code.  In Markdown, this would look like:

We're going to explore KNN with feature normalization and with k = 3 to 5 because we think X based on Y -- a bullet or two is fine.  
Code that does executes this
Plots and/or results  that show what happened
Brief Interpretation--a sentence or 2 is fine--of what happened
Rinse, repeat.
